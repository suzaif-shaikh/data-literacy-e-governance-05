# 📊 Policy Impact Analysis Using Public Sector Data

## 📌 Project Overview
This project focuses on analysing the impact of digital public service initiatives using data analytics techniques. It explores service transactions, online adoption, citizen satisfaction, processing time, and complaint resolution to identify trends and generate meaningful insights.

## 🎯 Project Objectives
- Analyse public sector service data.
- Perform data cleaning and preprocessing.
- Calculate Key Performance Indicators (KPIs).
- Identify trends and patterns.
- Conduct statistical analysis.
- Generate data-driven insights and recommendations.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Python
- Pandas
- NumPy
- Matplotlib
- Microsoft Word

## 🔍 Project Workflow
1. Dataset Collection
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis
4. KPI Calculation
5. Statistical Analysis
6. Data Visualization
7. Insights and Recommendations
8. Final Report Preparation

## 📈 Key Performance Indicators
- Total Service Transactions
- Online Service Adoption Rate
- Average Processing Time
- Citizen Satisfaction Rate
- Complaint Resolution Rate
- Digital Access Index

## 📊 Key Findings
- Analysed yearly public service transaction trends.
- Evaluated online service adoption.
- Compared citizen satisfaction across years.
- Examined state-wise service performance.
- Identified opportunities for public service improvements.

## 💡 Recommendations
- Improve digital accessibility.
- Reduce service processing time.
- Enhance citizen satisfaction.
- Strengthen complaint resolution systems.
- Improve transparency in public services.

## 📁 Dataset Information
The project uses a hypothetical dataset created for educational and analytical purposes. It does not represent actual government statistics.
